# User Feedback Rules

El feedback de usuarios reales debe analizarse antes de implementar.

No todo feedback debe convertirse automáticamente en una funcionalidad.

Clasificar:

- Problema real.
- Solución propuesta.
- Impacto.
- Prioridad.

Priorizar mejoras que:

- reduzcan fricción.
- mejoren experiencia.
- ayuden al profesional.

Evitar agregar funciones solamente porque alguien las solicita si contradicen la visión del producto.
