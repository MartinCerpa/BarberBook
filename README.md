# BarberBook

Frontend inicial de BarberBook, un producto de reservas y gestión para barberías.
Esta primera etapa presenta el perfil público de un barbero con datos simulados y
una interfaz responsive con modo claro y oscuro.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

## Comandos disponibles

- `npm run dev`: inicia el entorno de desarrollo.
- `npm run build`: genera la versión de producción.
- `npm run lint`: revisa el código.
- `npm run preview`: permite revisar la versión de producción localmente.

## Alcance actual

- Perfil público de un barbero.
- Catálogo de servicios basado en datos simulados.
- Selector de tema persistente.
- Diseño mobile-first.

Todavía no incluye backend, autenticación, pagos ni el flujo de reservas.
